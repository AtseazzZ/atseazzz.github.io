# zzz-island 博客设计说明

## 目标

构建一个名为 `zzz-island`、中文名为“Atsea_zzZ 的小岛”的个人博客。网站以技术札记为主，保留少量个人随记，用温暖、复古、有纸感的原创视觉降低工具感，让文章阅读成为首页的主要任务。

## 视觉方向

- 以暖米色纸张作为全局底色，使用墨黑文字和低饱和苔绿、砖红、蓝灰作栏目变化。
- 使用细手绘线条、轻微纸张颗粒、邮戳和纸页层叠表达记录感。
- 小动物只承担栏目导览、文章类型提示和少量情绪表达。首版使用原创的“岛屿信使”角色方向，不复制 TinyType Zoo 的角色、轮廓、气泡、模板构图或具体素材。
- 标题使用有编辑感的衬线字体，正文使用清晰的中文无衬线回退字体，确保长文阅读。
- 页面不用渐变背景和高密度装饰。卡片的边框、阴影和旋转只用于建立纸张层次。

## 信息架构

- 首页 `/`：站点身份、简介、最新文章、主题索引和小岛手记入口。
- 文章页 `/posts/<slug>`：标题、日期、标签、正文、目录和文章导航。
- 归档页 `/archive`：按月份分组的文章列表。
- 关于页 `/about`：作者介绍、技术栈、联系入口和站点说明。

## 技术架构

- 使用 VitePress 生成静态 HTML，Markdown 保存文章。
- 通过自定义主题实现首页、文章布局、归档页和关于页。
- 默认仓库目标为 `AtseazzZ.github.io`，VitePress `base` 使用 `/`。
- GitHub Pages 使用 GitHub Actions 构建 `.vitepress/dist` 并发布。
- 使用静态页面路由，不依赖需要服务器重写的客户端 history fallback。

## 首版内容

- 提供两篇真实可读的示例文章，分别体现技术札记和个人随记。
- 每篇文章包含标题、日期、摘要、标签、作者和正文。
- 首页首屏直接呈现最新文章入口，不使用营销式 hero 或空泛指标。

## 验收标准

- `npm run docs:build` 成功生成 `.vitepress/dist`。
- 本地预览可访问首页、两篇文章、归档页和关于页。
- 桌面和移动宽度下无横向溢出，中文标题与正文不重叠、不裁切。
- GitHub Actions 工作流只依赖仓库内的构建脚本，并将构建产物发布到 Pages。
